# 🏠 Housing Market Data Analysis  Report 

## 📌 Project Overview

This project presents an interactive **Housing Market Data Analysis Report** developed using **Microsoft Power BI** 

The dashboard analyzes housing sales, property prices, regional performance, property types, sales patterns, and other key housing market indicators to generate meaningful business insights.

---

## 🎯 Project Objective

The main objective of this project is to transform raw housing market data into an interactive and easy-to-understand **Business Intelligence dashboard**.

The analysis focuses on:

* Housing sales performance
* Property pricing trends
* Regional and city-wise performance
* Property type analysis
* Sales type analysis
* Price segment analysis
* Room-wise pricing
* Property size and purchase price relationships

---

## 📊 Dashboard Overview

The Power BI report consists of **4 interactive pages**:

### 1. 📈 Overview

Provides a high-level summary of the housing market using important KPIs and trend analysis.

**Key metrics include:**

* Total Sales
* Average Property Price
* Average Price per Sqm
* Year-over-Year (YOY) Growth
* Yearly Sales Trend
* Quarterly Sales Trend
* Regional Sales Performance

---

### 2. 🌍 Regional Analysis

Analyzes housing performance across different regions and cities.

**Key analysis:**

* City-wise Sales
* Regional Sales Distribution
* Property Distribution by Region
* House Type Distribution
* Regional Price Comparison
* Geographic Housing Market Analysis

---

### 3. 🏘️ Property Insights Analysis

Provides deeper analysis of property characteristics and pricing.

**Key analysis:**

* Sales by Price Segment
* Sales by Sales Type
* Average Price by House Type
* Average Price by Number of Rooms
* Property Size Analysis
* Purchase Price Analysis
* Property Characteristics

---

### 4. 🔎 Property Details

Provides detailed property-level information for deeper exploration.

**Includes:**

* City
* Region
* House Type
* Number of Rooms
* Property Size (Sqm)
* Purchase Price
* Sales Type
* Property Details

Interactive filters allow users to explore specific properties and market segments.
